# ФЕРЗИ — демонстрационный сайт

## Как открыть на компьютере
1. Распакуйте архив в отдельную папку.
2. Откройте папку `ferzi_site`.
3. Дважды нажмите `index.html` — сайт откроется в браузере.

Интернет для локального просмотра не требуется.

## На телефоне
Передайте ZIP на телефон, распакуйте его и откройте `index.html` в браузере. Если телефон не разрешает открывать локальные HTML-файлы, сайт можно будет разместить на хостинге.

## Важно
Это визуальный прототип. Пароль `FERZI-DEMO` — только демонстрация, он не защищает реальные данные. Для публикации личных материалов понадобится серверная авторизация и админ-панель.


## Обновление карточек персонажей
В папке `assets` находятся портреты Карахана и Сергса. Карточка Чигура пока оставлена как заглушка до получения его изображения.
