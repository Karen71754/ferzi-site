# ФЕРЗИ — сайт сообщества

## Структура проекта

- `index.html` — главная страница.
- `styles.css` — оформление и адаптивная верстка.
- `script.js` — интерактивные элементы.
- `karahan.jpg` — портрет Карахана.
- `sergs.jpg` — портрет Сергса.

## Публикация

Проект связан с Vercel. Изменения в основной ветке `main` автоматически запускают новую публикацию сайта.

Публичный адрес: https://ferzi-site.vercel.app/

## Важно

Пароль `FERZI-DEMO` в текущей версии является только демонстрационной проверкой на стороне браузера. Он не защищает закрытые материалы и не должен использоваться для хранения конфиденциальной информации. Для реальной защиты понадобится серверная авторизация.
